# Shopee Mobile Shopping Prototype

Prepared by Dwight Karl B. Gaga-a for IT1814 Laboratory Exercise 1.

An academic interface prototype with illustrative products, prices and simulated orders. Not affiliated with Shopee. No sign-in, payment gateway or real order processing is connected.

## Run locally
Open index.html in a web browser. No install or build step is required.

## Publish with GitHub Pages
1. Create a public GitHub repository named shopee-mobile-prototype.
2. Extract this ZIP and upload index.html, .nojekyll and README.md to the repository root. Upload the extracted files, not the ZIP itself.
3. Open Settings > Pages. Under Build and deployment, select Deploy from a branch.
4. Choose main and /(root), then Save.
5. Wait for GitHub to display the published site link.

## Demo flow
Search for keyboard, compare the two keyboards, choose a color, add one to the cart, apply STUDENT50 and place a test order. Track the order using the simulated delivery timeline.

All demo state stays in memory and resets when the page is refreshed.
